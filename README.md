# 🤖 VEXA - Kişisel Yapay Zeka Sistemi

**VEXA**, günlük işlerinizi kolaylaştırmak, sorularınıza hızlı yanıtlar üretmek ve kişisel verimliliğinizi artırmak için geliştirilmiş web tabanlı bir yapay zeka asistanıdır.

🔗 **Canlı Demo:** [VEXA'yı Hemen Deneyin](https://vexa-ai-haktan.web.app/)

## ✨ Öne Çıkan Özellikler

* **Akıllı Sohbet ve Soru-Cevap:** Doğal dil işleme yeteneği ile karmaşık sorulara anlaşılır yanıtlar verir.
* **Hafıza ve Bağlam Yönetimi:** Konuşma geçmişini ve kullanıcı tercihlerini hatırlayarak kişiselleştirilmiş deneyim sunar.
* **Hızlı ve Sade Arayüz:** Hem masaüstü hem de mobil cihazlarda akıcı çalışan modern tasarım.
